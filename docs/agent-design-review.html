Design an agent in a thread, not a form

The drawer's Design the agent used to open a form with five pre-formulated questions. It now starts a special kind of new thread: Weft hands over the brief, the thread asks the questions and writes the soul.

What the button does now

  1. 1The drawer starts a thread — with the brief as its prompt, and a page of its own already written.
  2. 2The thread asks — one question at a time, and only the ones that change what it writes.
  3. 3The thread writes the soul — standing instructions, not a description — and saves it with create_agent.
  4. 4The agent lands — in Settings → Agents, ready to pick as a card's agent.

The pieces

lib/agent-thread.ts

The brief (project + job) and the prompt the designing thread runs on.

lib/agent-brief-page.ts

The page the thread opens on: the brief, and what happens next.

app/api/agents/design

POST {project, job} → the card, the start, and the show file. Only Weft's own window.

components/IssueWorkflowPicker.tsx

The Land in control, the skill and agent pickers, and the design button.

The prompt the thread runs on

Help me design an agent for weft that triages this project's GitHub issues

Ask me what you need to know — one question at a time, and only the
ones that change what you write. Do not ask me what I already said.

Then write the agent's soul and save it with the create_agent tool.

What went away

The old interview is gone: lib/agent-interview.ts, app/api/agents/interview, the two client methods and the InterviewQuestion type. Nothing else in Weft used them.
